HƯỚNG DẪN SỬ DỤNG CÁC LỆNH TRONG AUTOCAD:
--------------------------------------------------------------------------------

1. LỆNH TRA CỨU ĐỊA CHÍNH:
   - Gõ lệnh: FF (hoặc TC)
     + Tìm kiếm trên bản vẽ đang mở: Nhập số thửa / tờ / tên chủ đất vào ô tìm kiếm.
     + Tìm kiếm xuyên hàng nghìn bản vẽ trong thư mục:
       * Tích BẬT công tắc [v] Tìm trong thư mục.
       * Nhấp [Chọn Thư Mục...] trỏ tới thư mục chứa các file .DWG.
       * Nhấp [Cập Nhật Chỉ Mục] (chỉ cần chạy 1 lần để hệ thống nạp dữ liệu siêu tốc).
       * Nhập từ khóa cần tìm -> Danh sách kết quả hiện ra ngay lập tức (< 1 giây)!
       * Nhấp đúp chuột vào kết quả để tự động mở bản vẽ và Zoom chuẩn tọa độ VN-2000.
   - Gõ lệnh: CTTM (hoặc FFO) -> Bật / Tắt nhanh chế độ tìm kiếm thư mục.
   - Gõ lệnh: FFF  (hoặc TCTM) -> Mở trực tiếp chế độ tìm kiếm thư mục.
   - Gõ lệnh: FFL              -> Mở lại bảng kết quả tìm kiếm thư mục vừa tra cứu.
   - Gõ lệnh: GOPBANDO (GBD)   -> Gộp tất cả các tờ bản đồ .DWG trong thư mục vào 1 bản vẽ.

2. LỆNH ĐỔI FONT & SỬA LỖI FONT TOÀN NĂNG:
   - Gõ lệnh: DF (hoặc DOIFONT)
     -> Mở BẢNG ĐỔI FONT:
        [1] Chuyển toàn bộ bản vẽ sang ARIAL UNICODE (Khuyên dùng - Đọc 100% chữ tiếng Việt)
        [2] Đổi toàn bộ kiểu chữ sang .VnArial (TCVN3 - Tiếng Việt ABC)
        [3] Đổi toàn bộ kiểu chữ sang VNTIME.SHX (Font nét đơn CAD)
        [4] Quét & tự động sửa lỗi từng chữ (Lệnh SF)
        [5] Kiểm tra tình trạng font bản vẽ (Lệnh KTFONT)
   - Gõ lệnh: SF (hoặc SUAFONT / CV)
     -> Tự động quét và sửa toàn bộ lỗi font, giải mã đa bảng mã (TCVN3, VNI sang Unicode chuẩn)
        Sửa các lỗi biến dạng: "?Êt tranh chÊp" -> "đất tranh chấp", "4/1 Êp CÇu X©y" -> "4/1 Ấp Cầu Xây".
   - Gõ lệnh: ALL2ARIAL  -> Đổi tất cả Style sang Arial Unicode.
   - Gõ lệnh: ALL2VN     -> Đổi tất cả Style sang .VnArial (TCVN3).
   - Gõ lệnh: ALL2SHX    -> Đổi tất cả Style sang font nét đơn VNTIME.SHX.

3. LỆNH TĂNG TỐC AUTOCAD:
   - Gõ lệnh: TT (hoặc BOOST)
     -> Tối ưu hóa toàn bộ biến hệ thống AutoCAD, chuột mượt mà 100%, khử giật lag khi zoom pan.
